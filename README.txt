DISCIPLINE QUEST — PHONE PWA

This is an offline-first mobile web app.

EASIEST USE:
1. Put this folder on any static web host.
2. Open its index.html URL on your phone.
3. Browser menu -> Add to Home screen.
4. It will open like an app.

No account is required. Progress is stored in the browser's local storage.

FEATURES:
XP/levels, coins, daily quests, streak, consistency, workout logging,
PR tracking, weekly boss, achievements, map, stats, journal and local saving.
